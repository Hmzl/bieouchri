# Boutika

Application mobile (web) en français pour gérer un magasin et recevoir des commandes via WhatsApp.

## Lancer l’application

```bash
npm install
npm run dev
```

Ouvrez l’adresse affichée (souvent `http://localhost:5173`) sur votre ordinateur, ou sur votre téléphone en étant sur le même Wi‑Fi.

## Premiers pas

1. Sur l’accueil, choisissez **Je suis commerçant**.
2. Allez dans **Plus → Paramètres** et renseignez le **numéro WhatsApp** du magasin (indicatif pays inclus, ex. `2250700000000`).
3. Ajoutez vos produits (photo caméra ou galerie, prix, stock, catégorie).
4. Côté **Je suis client**, parcourez le catalogue, remplissez le panier, partagez la position GPS, puis envoyez la commande.

Pour tester rapidement, utilisez **Charger un magasin d’exemple** depuis l’accueil ou l’écran Plus.

Les données restent enregistrées dans le navigateur de l’appareil.
